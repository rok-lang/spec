# nok

The formal specification for the **nok** programming language.

Designed and maintained by [Han Damin](https://github.com/miniex) (`@miniex`).

## Languages

- [한국어](ko/README.md) — canonical
- English (`en/`) — planned, not yet available

The Korean version is the source of truth. All other language directories — once they exist — are translations.

## Status

Active draft. The Korean specification is being actively written. The implementation lives in a separate repository.
