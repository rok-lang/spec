# Contributing to the rok specification

This repository is the rok language and standard-library specification, in two
editions: English (`en/`) and Korean (`ko/`).

## Keeping the editions in sync

A change to one edition is mirrored in the other in the same change, with the
same section numbers and heading anchors. Cross-references use the generated
`.html` anchors (GitHub heading rules).

## Style

Normative prose is precise and spare. Code examples are valid rok or ROKON.

## Submitting

Open a pull request against `main`. The spec text is licensed CC BY 4.0; by
contributing you agree to license your work the same way.
