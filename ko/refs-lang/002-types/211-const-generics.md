# 2.11. `const` 제네릭

`const` 제네릭은 [제네릭](210-generics.md) 매개변수 자리에서 값을 받습니다. 컴파일 타임에 정해지는 정수, 진리값, 짧은 표현식이 매개변수가 됩니다.

## 2.11.1. 동기

배열 길이, 행렬 차원, 임베디드 메모리 풀 크기처럼 컴파일 타임에 정해지는 값을 타입의 일부로 다루려는 것입니다.

```rok
struct Matrix<T, const M: usize, const N: usize> {
    data: [T; M * N];
}

fn dot<T: Num, const N: usize>(a: [T; N], b: [T; N]) -> T { ... }
```

배열 길이가 타입의 일부가 되므로 호출할 때 길이를 검사하는 비용이 들지 않습니다. 컴파일러는 SIMD나 언롤링처럼 길이에 의존하는 최적화를 할 수 있습니다. 행렬 곱처럼 차원 호환성이 중요한 연산도 컴파일 타임에 검증할 수 있습니다.

## 2.11.2. 선언 형태

```rok
const 매개변수이름 : 타입
```

`const` 키워드 뒤에 매개변수 이름, `:`, 타입이 차례로 옵니다. 타입은 아래에서 설명하는 허용 `const` 타입 중 하나여야 합니다.

매개변수가 여럿이면 콤마로 구분합니다. 타입 매개변수와 `const` 매개변수는 자유롭게 섞을 수 있습니다.

```rok
fn replicate<T, const N: usize>(value: T) -> [T; N] { ... }
struct Tagged<T, const TAG: u32> { value: T; }
```

## 2.11.3. 허용 타입

`const` 매개변수의 타입은 정수형(`i8` ~ `i128`, `u8` ~ `u128`, `usize`, `isize`), `bool`, `char`, `c_char` 중 하나입니다.

부동소수, 합 타입, 직접 정의한 struct는 `const` 매개변수가 될 수 없습니다. 부동소수는 비트 표현이 비결정적이어서 제외합니다. 직접 정의한 타입은 동등 비교의 일관성 문제 때문에 제외합니다.

## 2.11.4. 인스턴스화 시 인자

호출 지점이나 인스턴스화 지점에서 `const` 매개변수에 `const` 표현식을 넘깁니다.

```rok
let m: Matrix<f64, 3, 4> = ...;
let v: [i32; 16] = ...;
let arr = replicate::<f64, 8>(0.0f64);
```

인자는 컴파일 타임에 평가할 수 있어야 합니다. 리터럴, `const` 변수, `const` 함수 호출, 다른 `const` 매개변수, 그리고 이들의 단순 산술 조합을 쓸 수 있습니다. 런타임 변수는 `const` 인자 자리에 쓸 수 없습니다. 쓰면 컴파일 에러입니다.

제네릭 인자 목록에서 중괄호 없이 쓸 수 있는 인자는 리터럴, 부호를 뒤집은 리터럴(`-1`), 이름(`N`, `const` 변수)입니다. 산술을 포함한 그 밖의 식은 중괄호로 감쌉니다.

```rok
fn grow<const N: usize>(b: Buf<N>) -> Buf<{ N + 1 }> { ... }
let b: Buf<{ 2 * 8 }> = ...;
```

배열 길이(`[T; M * N]`)는 이미 식 자리이므로 중괄호가 필요 없습니다.

## 2.11.5. `const` 표현식의 산술

`const` 매개변수 사이의 단순 산술을 타입 안에서 쓸 수 있습니다.

```rok
struct Matrix<T, const M: usize, const N: usize> {
    data: [T; M * N];
}

fn flatten<T, const M: usize, const N: usize>(
    m: Matrix<T, M, N>
) -> [T; M * N] { ... }
```

쓸 수 있는 연산자는 `+`, `-`, `*`, `/`, `%`, 단항 `-`입니다. 현재 사양에서는 비교와 조건 분기를 쓸 수 없고, 단순 산술만 쓸 수 있습니다. 타입 시스템은 `M * N`과 `N * M`이 같은 값임을 인식합니다(교환 법칙).

조건 분기나 재귀처럼 더 복잡한 `const` 표현식은 `const` 함수 사양에서 다룹니다.

## 2.11.6. 매개변수 추론

`const` 인자는 인자의 타입, struct 필드의 타입, 기대 타입(`let` 주석, 매개변수 타입, 반환 타입)에서 추론할 수 있으면 생략할 수 있습니다.

```rok
fn replicate<T, const N: usize>(value: T) -> [T; N] { ... }

let arr: [i32; 8] = replicate(0i32);     // N = 8 추론
let arr2 = replicate::<i32, 8>(0i32);    // 명시
```

추론 우선순위와 모호성 해소는 표현식 사양에서 정의합니다.

### 반복 리터럴 `[v; N]`

`[v; N]`은 값 `v`를 `N`번 반복한 `[T; N]` 배열입니다. `N`은 `const` 표현식이고, `const` 매개변수여도 됩니다.

```rok
fn zeros<const N: usize>() -> [f64; N] { [0.0; N] }
let z: [f64; 4] = zeros();              // N = 4, 기대 타입에서
let w = [1u8; 16];                       // [u8; 16]
```

## 2.11.7. 단형화

`const` 제네릭은 [제네릭](210-generics.md)의 단형화와 같은 방식으로 동작합니다. 컴파일러는 `const` 인자 조합마다 따로 컴파일합니다.

```rok
let a = replicate(0i32);    // N = ?, 추론 시점에 결정
```

`const` 인자 조합이 같은 호출은 결과를 공유합니다.

## 2.11.8. 동등성

`const` 인자의 값이 같은 두 타입은 같은 타입입니다.

```rok
let a: [i32; 4] = ...;
let b: [i32; 2 + 2] = ...;
// a 와 b 는 같은 타입
```

`const` 표현식 평가가 결정론적이므로 이 동등성이 성립합니다.

## 2.11.9. 정의 가능 위치

`const` 제네릭은 다음 위치에서 모두 같은 문법으로 쓸 수 있습니다. 함수와 메서드, struct와 `enum`, `union`, 그리고 트레잇, `impl` 블록, 타입 별칭입니다.

[제네릭](210-generics.md)의 일반 제네릭과 같은 규칙이므로 따로 외울 규칙이 없습니다.

## 2.11.10. 인덱스로 사용

`const` 매개변수는 일반 `const` 변수처럼 값 위치에서 그대로 쓸 수 있습니다.

```rok
fn first<T, const N: usize>(arr: [T; N]) -> T {
    arr[0]
}

fn middle<T, const N: usize>(arr: [T; N]) -> T {
    arr[N / 2]
}
```

값 위치에서 쓰는 정확한 규칙은 표현식 사양에서 정의합니다.
