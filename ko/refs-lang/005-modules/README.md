# 5. 변수 / 모듈 / 가시성 / 패키지 개요

## 명명 공간의 네 단계

```
패키지 (package)
  └── 모듈 (module)
        └── 항목 (item)
              └── 지역 변수 (local)
```

위에서 아래로 포함 관계다. 한 패키지는 여러 모듈을, 한 모듈은 여러 항목 (함수, 타입, 트레잇, `const`, `static`) 을, 한 항목 (특히 함수 본체) 은 여러 지역 변수를 가진다.

각 단계의 경계 규칙은 다음 문서들에서 정의한다.

## 패키지: 가장 큰 단위

[소스 단위](../000-meta/003-source-units.md) 에서 정의한 패키지가 명명 공간의 가장 바깥이다. 패키지마다 내용 기반 해시를 식별자로 부여한다.

같은 패키지 안의 모든 항목은 같은 코드 권한 영역에 속한다. [`impl`](../002-types/209-impl.md) 의 orphan 규칙이 패키지 단위로 적용되는 근거다.

## 모듈: 패키지 안의 묶음 단위

한 패키지는 여러 모듈을 가진다. 각 모듈은 단일 파일 (`foo.nok`) 또는 디렉토리 안의 `.nok` 파일들 (`foo/` 안의 모든 `.nok` 파일이 합쳐서 본체) 중 한 형태를 취한다. 자세한 규칙은 [모듈](504-modules.md) 에서 정의한다.

```
my_pkg/
├── lib.nok                  ← 패키지 루트 모듈 (단일 파일)
├── geom.nok                 ← geom 모듈 (단일 파일)
└── parsing/                 ← parsing 모듈 (디렉토리 안 파일들이 합쳐서 본체)
    ├── lexer.nok            ← parsing 본체의 일부
    └── parser.nok           ← parsing 본체의 일부
```

## 항목: 모듈 안의 명명된 정의

각 모듈은 항목을 가진다. 함수, 타입, 트레잇, `impl` 블록, `const`, `static`, 다른 모듈 선언이 여기 해당한다.

[함수 선언](../004-functions/401-function-declaration.md), [`struct`](../002-types/203-struct.md), [`enum`](../002-types/204-enum.md), [`trait`](../002-types/208-trait.md), [`impl`](../002-types/209-impl.md) 의 모든 정의가 모듈 안의 항목이 된다.

## 지역 변수: 함수 / 블록 안의 변수

함수, 블록, 다른 식 안에서 지역 변수를 `let` 키워드 ([키워드](../001-lexical/105-keywords.md)) 로 선언한다.

```nok
fn area(r: f64) -> f64 {
    let pi = 3.14159f64;          // 지역 변수
    pi * r * r
}
```

지역 변수의 가시 범위는 [블록 표현식](../003-expressions/309-block-expressions.md) 의 블록 단위다. 자세한 규칙은 [변수 선언](501-variable-declaration.md) 에서 정의한다.

## 가시성: 항목의 외부 노출

각 항목에는 가시성이 있다. 가시성 단계 ([가시성](506-visibility.md)) 가 항목이 어디까지 보이는지 결정한다.

```
private (기본)        같은 모듈 안에서만
pub(shy)             외부에서 명시 import 만 가능 (glob 차단)
pub(sub)             하위 모듈에서만
pub(pkg)             같은 패키지 안에서만
pub                  외부 패키지에서도 가능
```

## 이름 해소: 어디서 어떤 항목을 가리키는가

코드의 한 이름이 어떤 항목을 가리키는지 결정하는 과정을 이름 해소 (name resolution) 라 한다.

이 과정은 다음 정보를 종합한다.

- 현재 모듈의 지역 가시 항목.
- `use` 로 가져온 외부 항목 ([`use`](505-use.md)).
- 자동 가시 prelude ([표준 라이브러리 계층](../000-meta/005-stdlib-tiers.md)).
- 가시성 검사. 볼 수 있는 항목만 후보가 된다.

이름 해소는 컴파일 타임에 일어난다. 동적 슬롯의 메서드 디스패치는 런타임이지만, 이름 자체의 해소는 컴파일 타임이다.
