# 1.9. 진리값과 센티넬 리터럴

Rok에는 키워드처럼 생겼지만 실제로는 값을 뜻하는 리터럴이 세 가지 있습니다. 문법은 다음과 같습니다.

```
sentinel_lit    ::= "true" | "false" | "none"
```

## 1.9.1. 진리값 리터럴

진리값 리터럴은 다음과 같이 적습니다.

```rok
true
false
```

진리값 리터럴은 `true`와 `false`, 정확히 두 토큰입니다. 이 두 이름은 [키워드](105-keywords.md)의 예약 목록에 있으므로 식별자로 쓸 수 없습니다. 평가 결과의 타입은 표준 라이브러리의 진리값 타입(`bool`)이며, 정확한 정의는 타입 시스템에서 다룹니다.

## 1.9.2. 센티넬 리터럴: `none`

센티넬 리터럴은 다음과 같이 적습니다.

```rok
none
```

`none`은 값이 없음을 나타내는 유일한 리터럴입니다. 다른 언어의 `null`, `nil`, `None`, `undefined`에 해당하며, 키워드로 예약되어 있어 식별자로 쓸 수 없습니다. 어느 합 타입의 빈자리를 채우는지는 문맥이 정하며, 그 의미론은 타입 시스템 사양에서 정의합니다.

## 1.9.3. 어휘적 분류

세 리터럴은 [어휘 구조](102-lexical-structure.md)의 진리값 / 센티넬 리터럴 분류에 속합니다. 키워드 토큰과 따로 분류하는 이유는 이 토큰들이 값 자리에 나오고, 구문 분석기가 리터럴이 올 자리에서 받아들이기 때문입니다.

어휘 단계에서 보장하는 것은 하나입니다. `true`, `false`, `none`은 항상 같은 토큰 종류로 분리되며, 식별자나 다른 키워드로 다시 해석되지 않습니다.

## 1.9.4. 도입하지 않는 리터럴

다른 언어에서 흔한 다음 리터럴은 어휘 단계의 별도 토큰으로 두지 않습니다. 부동소수의 무한대와 NaN은 표준 라이브러리 상수로 제공하고, "비어 있음"의 다른 형태인 `undefined`, `null`, `nil`은 모두 `none` 하나로 합칩니다. **unit** 값(`()`)은 어휘 단계가 아니라 표현식 단계에서 빈 튜플 표기로 나옵니다.

리터럴 종류가 적을수록 학습 비용과 도구 표면이 작아집니다.
