# 1.9. 진리값과 센티넬 리터럴

키워드의 형태이지만 값을 의미하는 세 가지 리터럴.

```
sentinel_lit    ::= "true" | "false" | "none"
```

## 1.9.1. 진리값 리터럴

```nok
true
false
```

- 정확히 두 개의 토큰. `true` 와 `false`.
- [키워드](105-keywords.md) 의 예약 목록에 포함되어 있어 식별자로 재사용할 수 없다.
- 평가되는 타입은 표준 라이브러리의 진리값 타입 (`bool`). 정확한 정의는 타입 시스템에서.

## 1.9.2. 센티넬 리터럴: `none`

```nok
none
```

`none` 은 값의 부재를 표현하는 단일 리터럴이다.

- 다른 언어의 `null`, `nil`, `None`, `undefined` 에 해당하는 자리다.
- 키워드로 예약된다. 식별자로 쓸 수 없다.
- 어떤 합 타입의 빈 자리를 채우는지는 문맥이 결정한다. 의미론은 타입 시스템 사양에서
  정의한다.

## 1.9.3. 어휘적 분류

세 리터럴은 [어휘 구조](102-lexical-structure.md) 의 _진리값 / 센티넬 리터럴_ 분류에 속한다. 키워드 토큰
종류와 별도로 분류되는 이유는 값의 자리에 등장하는 토큰이며, 구문 분석기가 리터럴이 올
자리에서 받아들이기 때문이다.

어휘 단계에서는 다음만 보장한다.

- `true`, `false`, `none` 은 항상 같은 토큰 종류로 분리된다.
- 식별자나 다른 키워드로 재해석되지 않는다.

## 1.9.4. 도입하지 않는 리터럴

다른 언어에서 흔한 다음 리터럴은 어휘 단계에서 별도 토큰으로 도입하지 않는다.

- 부동소수의 무한대와 NaN. 표준 라이브러리 상수로 제공한다.
- "비어있음" 의 또 다른 형태 (`undefined`, `null`, `nil`). `none` 으로 단일화한다.
- _unit_ 값 (`()`). 어휘 단계가 아니라 표현식 단계에서 빈 튜플 표기로 등장한다.

리터럴 종류가 적을수록 학습 비용과 도구 표면이 작다.
