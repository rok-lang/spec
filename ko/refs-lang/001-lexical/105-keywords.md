# 1.5. 키워드

키워드는 식별자처럼 보이지만 언어가 예약한 토큰이다. 식별자 위치에 키워드가 나타나면
컴파일러는 식별자가 아니라 키워드 토큰을 만든다.

본 문서는 언어가 직접 예약하는 키워드의 목록만 정의한다. 각 키워드의 정확한 의미는 후속
사양에서 도입한다. 본 문서는 형태와 분류만 명시한다.

## 1.5.1. 예약 키워드 목록

### 선언 / 변수

```
let       fn        struct    enum      union     trait     impl
type      const     static    mut       where     pub       mod       use
extern    as        ref
```

> [!NOTE]
> `mut` 는 오직 `extern "C" { ... }` 블록 안의 `static mut` 형태에서만 사용된다 ([`static`](../005-modules/503-static.md)).
> 일반 변수는 nok 에서 기본 가변이므로 일반 코드에 `mut` 가 등장하지 않는다.

### 제어 흐름

```
if        else      match     while     loop      for       in
break     continue  return    is
try       catch     throw     throws    finally
```

### 비동기 / 생성자

```
async     await     yield
```

### 자기참조 / 경로 시작점

```
self      Self      crate     super
```

- `self` (소문자). 인스턴스 식별자 또는 경로의 현재 모듈 시작점.
- `Self` (대문자). 현재 `impl` 의 대상 타입 이름.
- `crate`. 경로의 패키지 루트 시작점.
- `super`. 경로의 부모 모듈 시작점.

### 가시성 한정자 (`pub` 안)

```
pkg       sub       shy
```

`pub(pkg)`, `pub(sub)`, `pub(shy)` 의 괄호 안에서 쓰이는 한정자. 이 세 단어는 어디서든
키워드로 토큰화되며 식별자로 재사용할 수 없다. 일반 위치에 나타나면 그 자리에서
키워드 의미가 정해지지 않은 채로 컴파일 에러가 된다.

### 진리값 / 센티넬

```
true      false     none
```

### 타입 이름 슬롯

```
any
```

`any` 는 동적 슬롯을 가리키는 타입 이름이다. 의미는 타입 시스템 사양에서 정의한다. 본 문서
범위에서 중요한 사실은 식별자로 재사용할 수 없다는 점뿐이다.

## 1.5.2. 의미는 후속 문서에서

위 토큰들의 의미는 다음과 같이 분산되어 정의된다.

- 변수 / 가시성 / 모듈. 5장.
- 타입 / 컨테이너. 2장.
- 제어 흐름. 3장.
- 함수 / 클로저 / 코루틴. 4장.
- 메타 / 매직. 6장.

본 1장은 어휘 단계에서 이 토큰들이 식별자가 아니라 키워드로 분리된다는 분류 규칙만 다룬다.

## 1.5.3. 등록된 키워드 (확장 메커니즘)

위 예약 목록 외에, 표준 라이브러리가 추가 키워드를 등록할 수 있는 메커니즘이 있다. 메타
시스템의 일부다. 등록 메커니즘과 정확한 처리 규칙은 [`#[keyword(...)]` 매직](../006-meta-system/606-keyword-magic.md) 에서 정의한다.

본 문서 범위에서는 다음만 약속한다.

- 예약 키워드는 어떤 환경에서도 식별자가 아니다. 무조건 키워드로 분리된다.
- 등록된 키워드는 그 등록을 포함하는 컴파일 단위 안에서만 효력을 갖는다.
- 두 집합이 충돌하면 등록 시점에 거부된다. 예약 키워드는 덮어쓸 수 없다.

## 1.5.4. 컨텍스트 키워드의 부재

nok 은 컨텍스트 키워드(특정 위치에서만 키워드로 인식되는 단어) 를 도입하지 않는다.

위 목록의 모든 토큰은 어디에 나타나든 키워드로 토큰화된다. 식별자 자리에 나타나도
키워드다. 이 단순함을 위해 일부 영어 단어 (예: `loop`, `is`) 를 변수 이름으로 쓸 수 없게
되는 비용을 받아들인다.
