# 1.3. 문장 종결자

> [!IMPORTANT]
> nok 의 문장은 세미콜론 (`;`) 으로 끝난다. 줄바꿈은 문장을 끝내지 않는다.

```
stmt_terminator ::= ";"
```

## 1.3.1. 규칙

- 한 문장은 정확히 하나의 `;` 로 끝난다.
- 한 줄에 여러 문장이 올 수 있다.
- 한 문장이 여러 줄에 걸쳐도 무방하다. 줄바꿈은 토큰 사이의 공백일 뿐이다.

도식:

```
<문장> ;
<문장> ; <문장> ;             // 한 줄에 여러 개
<문장의
 일부가 여러 줄에 걸침> ;    // 여러 줄. 마지막 ; 에서 종료
```

## 1.3.2. 줄바꿈 자동 삽입을 두지 않는 이유

JavaScript 의 ASI (Automatic Semicolon Insertion), Go 의 줄 끝 자동 세미콜론, Swift 의
줄 단위 종료 같은 자동 규칙은 도입하지 않는다.

이유:

- 자동 규칙은 드문 경우에서 모호성을 만든다. JavaScript 의 ASI 함정이 잘 알려진 예다.
- 명시적 종결자가 있어야 도구(포매터, LSP, 에디터의 다음-문장 점프 등) 가 문장 경계를
  결정론적으로 알 수 있다.
- 한 줄에 여러 문장을 두는 표기 (REPL 의 빠른 입력 등) 가 자연스럽다.

## 1.3.3. 빈 문장

`;` 만 있는 빈 문장은 허용한다. 어떤 효과도 없다.

```nok
;;;
```

위는 세 개의 빈 문장으로 인식된다. 도구가 생성한 코드의 자유도를 위해 받아들인다.

## 1.3.4. 다른 토큰과의 결합

`;` 토큰은 앞뒤 토큰과 공백 없이 붙어도 된다. `<문장>;<문장>;` 처럼 빈틈없이 적어도 두
문장으로 정상 토큰화된다. 가독성을 위해 공백을 두는 쪽이 권장 스타일이며, 사양은 스타일을
강제하지 않는다.
