## 함수의 역할

함수는 입력 값을 받아 결과 값을 만드는 코드 단위입니다. Rok의 함수는 다음 성격을 모두 띨 수 있습니다.

이름으로 보면 `fn name(...)`으로 적는 이름 있는 함수와 `|...|`로 적는 익명 클로저가 있습니다. 타입 표기로 보면 함수는 정적이거나 점진적입니다. 매개변수에 타입을 적으면 정적입니다. 생략하면 호출 지점에서 제네릭 단형화가 일어납니다([`any` 슬롯](../002-types/202-any-slot.md), [제네릭](../002-types/210-generics.md)). 실행 모델로 보면 동기, 비동기, 제너레이터 형태를 모두 쓸 수 있습니다. 일반 함수, `async fn`(Future 반환), `yield fn`(Iterator 반환), `async yield fn`(Stream 반환)이 있습니다. 예외 동작으로 보면 함수는 예외를 던질 수 있거나 던질 수 없습니다. 시그니처에 `throws`를 두면 예외를 던질 수 있습니다([에러 제어 흐름](../003-expressions/314-error-control-flow.md)). 소속으로 보면 함수는 `impl` 블록 안에 정의해 어떤 타입에 딸린 메서드이거나, 모듈 수준의 자유 함수입니다.

## 두 형태의 함수 정의

함수를 정의하는 형태는 두 가지입니다.

### 명명된 함수

첫째는 이름이 있는 함수입니다.

```rok
fn area(r: f64) -> f64 {
    3.14159 * r * r
}
```

이 형태는 `fn` 키워드, 이름, 매개변수, 반환 타입, 본체로 이루어집니다. 모듈 수준이나 [`impl`](../002-types/209-impl.md) 블록 안에 정의할 수 있습니다.

### 익명 클로저

둘째는 이름이 없는 클로저입니다.

```rok
|x: f64| -> f64 { 3.14159 * x * x }
|x| x * 2
|| compute()
```

이 형태는 `|...|`로 매개변수 목록을 감싸고 그 뒤에 본체를 적습니다. 표현식 위치에 바로 씁니다. 변수에 대입하거나 함수 인자로 바로 넘길 수 있습니다.

컴파일러는 두 형태를 내부에서 같은 방식으로 처리합니다. 차이는 이름이 있는지, 클로저를 만들 때 환경을 캡처하는지뿐입니다.

## 호출

함수와 클로저 모두 `()`로 호출합니다.

```rok
let a = area(2.0f64);
let f = |x: f64| x * 2;
let b = f(3.0f64);
```

호출하면 인자를 매개변수에 맞춥니다. 정확한 규칙은 [매개변수](402-parameters.md)에서 정의합니다.

## 반환

본체 마지막 식의 값이 함수의 반환값입니다. 함수 본체는 [블록 표현식](../003-expressions/309-block-expressions.md)의 블록 규칙을 따릅니다.

```rok
fn add(x: i32, y: i32) -> i32 { x + y }
fn early(x: i32) -> i32 {
    if x < 0 { return 0; }     // 조기 종료에는 명시적 return
    x * 2
}
```

그래서 `return` 키워드는 없어도 됩니다. 마지막 식이 자동으로 반환됩니다. 자세한 규칙은 [반환](403-return.md)에 있습니다.

## 함수와 표현식

함수와 클로저는 값입니다. 변수에 대입하고, 다른 함수에 인자로 넘기고, 컬렉션에 넣을 수 있습니다.

```rok
let f = |x| x * 2;
let v = list.map(f);
let g = if cond { f } else { |x| x + 1 };
```

함수의 타입은 매개변수 타입과 반환 타입으로 이루어집니다. 자세한 정의는 [함수 타입](404-function-type.md)에 있습니다.

## 호출 디스패치

[트레잇-as-타입 금지](../002-types/212-trait-as-type-banned.md) 원칙에 따라 함수 호출에는 vtable 간접 호출이 없습니다.

이름 있는 함수는 정적으로 정해진 함수 주소를 직접 호출합니다. 클로저는 캡처한 환경과 코드 포인터의 묶음입니다. 클로저 호출은 캡처한 환경을 첫 인자로 넘기는 직접 호출입니다. 제네릭 함수는 [제네릭](../002-types/210-generics.md)의 단형화를 거쳐 호출 지점마다 직접 호출로 풀립니다.

따라서 함수와 클로저 호출은 원칙적으로 직접 호출이고 인라이닝할 수 있습니다. 성능은 일반 메서드 호출과 같습니다.
