## 함수의 역할

함수는 입력 값을 받아 결과 값을 만드는 코드 단위다. nok 의 함수는 다음 성격을 모두 가질 수 있다.

- 이름 있음 또는 없음. `fn name(...)` 으로 명명된 함수, `|...|` 으로 익명 클로저.
- 정적 또는 점진. 매개변수에 타입을 적으면 정적, 빠뜨리면 호출 지점에서 제네릭 단형화 ([`any` 슬롯](../002-types/202-any-slot.md), [제네릭](../002-types/210-generics.md)).
- 동기, 비동기, 생성자. 일반 함수, `async fn` (Future 반환), `yield fn` (Iterator 반환), `async yield fn` (Stream 반환).
- 잡힐 수 있거나 던지는. 시그니처에 `throws` 를 두면 예외를 던질 수 있다 ([에러 제어 흐름](../003-expressions/314-error-control-flow.md)).
- 메서드 또는 자유 함수. `impl` 블록 안에서 정의되어 어떤 타입에 부속되거나, 모듈 수준의 자유 함수로 있다.

## 두 형태의 함수 정의

### 명명된 함수

```nok
fn area(r: f64) -> f64 {
    3.14159 * r * r
}
```

`fn` 키워드 + 이름 + 매개변수 + 반환 타입 + 본체. 모듈 수준이나 [`impl`](../002-types/209-impl.md) 블록 안에 정의 가능.

### 익명 클로저

```nok
|x: f64| -> f64 { 3.14159 * x * x }
|x| x * 2
|| compute()
```

`|...|` 로 매개변수 묶음을 둘러싸고 그 뒤에 본체. 표현식 위치에 직접 등장하며, 변수에 대입하거나 함수 인자로 그대로 전달.

두 형태는 내부에서 같은 메커니즘으로 처리된다. 차이는 이름이 있는지, 호출 지점에서 환경을 캡처하는지뿐이다.

## 호출

함수와 클로저 모두 `()` 로 호출한다.

```nok
let a = area(2.0f64);
let f = |x: f64| x * 2;
let b = f(3.0f64);
```

호출 시 인자가 매개변수에 매칭된다. 정확한 매칭 규칙은 [매개변수](402-parameters.md) 에서 정의한다.

## 반환

본체의 마지막 식의 값이 함수의 반환값이다. [블록 표현식](../003-expressions/309-block-expressions.md) 의 블록 규칙을 함수 본체가 그대로 따른다.

```nok
fn add(x: i32, y: i32) -> i32 { x + y }
fn early(x: i32) -> i32 {
    if x < 0 { return 0; }     // 조기 종료에는 명시적 return
    x * 2
}
```

`return` 키워드는 필수가 아니다. 마지막 식이 자동으로 반환된다. 자세한 규칙은 [반환](403-return.md).

## 함수와 표현식

함수와 클로저는 값이다. 변수에 대입할 수 있고, 다른 함수에 인자로 넘길 수 있고, 컬렉션에 넣을 수 있다.

```nok
let f = |x| x * 2;
let v = list.map(f);
let g = if cond { f } else { |x| x + 1 };
```

함수의 타입은 [함수 타입](404-function-type.md) 에서 정의한다. 매개변수 타입과 반환 타입으로 이루어진다.

## 호출 디스패치

함수 호출의 디스패치는 [트레잇-as-타입 금지](../002-types/212-trait-as-type-banned.md) 의 원칙에 따라 vtable 간접 호출 없이 해소된다.

- 명명된 함수. 정적으로 결정된 함수 주소로 직접 호출.
- 클로저. 캡처된 환경 + 코드 포인터의 묶음. 호출은 캡처된 환경을 첫 인자로 넘기는 직접 호출.
- 제네릭 함수. [제네릭](../002-types/210-generics.md) 의 단형화로 호출 지점마다 직접 호출.

함수와 클로저 호출은 원칙상 직접 호출이며 인라이닝 가능. 성능은 일반 메서드 호출과 동등하다.
