# 1.3. `MaybeUninit<T>` - 미초기화 메모리

`rok::bare::mem` 모듈은 미초기화 메모리를 안전하게 다루는 wrapper와 관련 ops를 정의합니다. 일반 `T`는 항상 초기화되어 있음이 보장되지만, `MaybeUninit<T>`는 초기화 여부를 type 수준에서 명시합니다.

## 1.3.1. 동기 - 미초기화 read 는 UB

LLVM의 `freeze` 의미론(2022년 명확화)에 따라, 미초기화 메모리를 읽으면 정수형이라도 UB입니다. 단순히 "garbage 값"이 나오는 정도가 아닙니다. 컴파일러는 그 값을 아무렇게나 가정하고 코드를 변형할 수 있습니다.

```c
// C
int x;            // uninit
if (x == 0) { ... }   // 컴파일러가 x 의 값 임의 추정, true / false 양쪽 dead-code 가능
```

따라서 T 자체로는 미초기화 상태를 표현할 수 없으며, 별도의 wrapper가 필요합니다.

## 1.3.2. `MaybeUninit<T>`

```rok
struct MaybeUninit<T> { /* T 와 같은 size + align, 단 미초기화 가능 */ }

impl<T> MaybeUninit<T> {
    fn uninit() -> MaybeUninit<T>;          // 미초기화 슬롯
    fn zeroed() -> MaybeUninit<T>;          // 0 으로 채움
    fn new(value: T) -> MaybeUninit<T>;     // 초기화된 슬롯

    fn write(ref self, value: T);           // value 쓰기

    fn as_ptr(self) -> ConstPtr<T>;
    fn as_mut_ptr(ref self) -> Ptr<T>;

    unsafe fn assume_init(self) -> T;
    // SAFETY: write / 외부 mechanism 으로 초기화 보장됐을 때만

}
```

`as_ptr` / `as_mut_ptr`의 receiver는 place여야 합니다. 포인터는 사본이 아니라 그 변수를 가리킵니다. `uninit()`은 `zeroed()`로 구현해도 됩니다.

### 사용 예 - 초기화 단계 분리

FFI가 buffer를 채우기를 기다렸다가 값을 꺼내는 전형적인 패턴입니다.

```rok
let buf: MaybeUninit<[u8; 1024]> = MaybeUninit::uninit();
let p: Ptr<u8> = buf.as_mut_ptr().cast::<u8>();

unsafe {
    read_from_kernel(p, 1024);              // FFI 가 buf 채움
    let initialized: [u8; 1024] = buf.assume_init();
}
```

### `write` 후 사용

`write`는 값을 기록할 뿐 참조를 돌려주지 않습니다(Rok에는 `ref` 반환이 없습니다). 기록한 뒤에는 `assume_init`으로 값을 꺼냅니다.

```rok
let slot: MaybeUninit<Big> = MaybeUninit::uninit();
slot.write(big_value());
let v: Big = unsafe { slot.assume_init() };
process(v);
```

## 1.3.3. `Pod` 트레잇

```rok
trait Pod { /* marker */ }
```

Plain Old Data의 약자로, 모든 bit pattern이 유효한 type을 뜻합니다. [1.2 cast](102-cast.md#125-reinterpreta-pod-b-pod---bit-cast-안전)의 `reinterpret`가 바로 이 marker를 요구합니다.

| 자동 impl                                    | 적용 안 됨                          |
|----------------------------------------------|-------------------------------------|
| 모든 정수 (i*, u*)                           | `Ptr<T>` (provenance)               |
| 모든 부동소수 (f*)                           | 사용자 struct (#[derive(Pod)] 명시) |
| `[T; N]` (T:Pod)                             | enum (variant tag, niche)          |
| `(T, U, ...)` (모두 Pod)                     |                                     |
| `c_char`                                     |                                     |
| `bool`, `char` (모든 bit pattern이 유효하지는 않음: 호출자가 검사, 1.2.5) |       |

### `Pod` 가 보장하는 것

`Pod`는 다음 세 가지를 함께 보장합니다.

1. 모든 bit pattern read가 안전합니다. uninit 노출이 없습니다.
2. **layout 결정론적**: `#[repr(C)]` 또는 `#[repr(transparent)]`가 강제됩니다.
3. **no Drop**: `Drop`이 구현돼 있으면 `Pod`는 자동으로 거부됩니다.

```rok
#[derive(Pod)]
#[repr(C)]
struct Vec3 { x: f32; y: f32; z: f32; }
// → reinterpret OK, ffi 안전, etc.
```

## 1.3.4. raw mem ops - read / write

저수준 메모리 조작용 free function은 다음과 같습니다.

```rok
unsafe fn read<T>(src: ConstPtr<T>) -> T;
unsafe fn write<T>(dst: Ptr<T>, value: T);
unsafe fn read_volatile<T>(src: ConstPtr<T>) -> T;
unsafe fn write_volatile<T>(dst: Ptr<T>, value: T);

unsafe fn copy<T>(src: ConstPtr<T>, dst: Ptr<T>, count: usize);
                                               // memmove (overlap OK)
unsafe fn copy_nonoverlapping<T>(src: ConstPtr<T>, dst: Ptr<T>, count: usize);
                                               // memcpy (overlap UB, 더 빠름)

unsafe fn write_bytes<T>(dst: Ptr<T>, value: u8, count: usize);
                                               // memset (모든 byte = value)

unsafe fn swap<T>(a: Ptr<T>, b: Ptr<T>);
unsafe fn replace<T>(dst: Ptr<T>, value: T) -> T;     // 기존 read + write
unsafe fn drop_in_place<T>(p: Ptr<T>);               // drop glue 실행 (메모리 free X)
```

대부분은 `Ptr<T>`의 메서드로도 노출돼 있으며(1.1.2), 이 module의 free function은 그 **ergonomic 대안**입니다.

`drop_in_place`는 drop glue를 실행합니다. 그 타입 자신의 `drop`을 먼저, 그다음 필드들의 `drop`을 선언 역순으로 실행합니다([2.13.4](../200-core/213-marker.md#2134-drop---using-해제-시-정리)).

## 1.3.5. `transmute_unchecked` - escape hatch

[1.2 cast](102-cast.md#126-transmute_uncheckeda-b---escape-hatch)에서 설명한 함수입니다. 정의는 이 module에 있고, `rok::bare::transmute_unchecked`는 tier 루트에서 다시 내보낸 것입니다.

```rok
unsafe fn transmute_unchecked<A, B>(a: A) -> B;        // size check 없음
```

## 1.3.6. align / size util

```rok
fn align_of<T>() -> usize;                  // T::align()
fn size_of<T>() -> usize;                   // T::size()
fn align_of_val<T>(val: T) -> usize;
fn size_of_val<T>(val: T) -> usize;         // 값으로 받음: unsized 타입 없음, size_of::<T>() 와 같음

fn min_align_of<T>() -> usize;              // align_of 와 같음 (Rust 호환)
```

이 함수들은 **unsafe가 아닙니다**. 사실상 `Reflect` 트레잇([2.12 reflect](../200-core/212-reflect.md))의 free function 형태이며, 편의를 위해 `rok::bare::mem` module에도 노출합니다. `size_of`와 `align_of`는 `rok::bare::ptr`(1.1.2)에 정의되며 여기서 다시 내보냅니다.

## 1.3.7. intrinsic 매핑

각 항목에 대응하는 컴파일러 intrinsic은 다음과 같습니다.

| 항목                           | intrinsic                     |
|--------------------------------|-------------------------------|
| `MaybeUninit::as_ptr` / `as_mut_ptr` | `rok.addr_of` (`assume_init`은 단순 필드 읽기) |
| `Pod`                          | (marker, derive 자동)        |
| `read` / `write`               | `rok.ptr.read` / `rok.ptr.write` (`Ptr` / `ConstPtr` 메서드 경유) |
| `read_volatile` / `write_volatile` | `rok.ptr.read_volatile` / `rok.ptr.write_volatile` |
| `copy` / `copy_nonoverlapping` | 없음: 원소 단위 `read` / `write` 루프 (`dst`가 `src`보다 위면 `copy`는 뒤에서부터) |
| `write_bytes`                  | 없음: byte 단위 쓰기 루프     |
| `drop_in_place`                | `rok.drop_in_place`           |
| `size_of` / `align_of`         | `rok.size_of` / `rok.align_of` |
| `buf_new` / `buf_get` / `buf_set` / `buf_same` | `rok.buf_new` / `rok.buf_get` / `rok.buf_set` / `rok.buf_same` |

## 1.3.8. 다른 언어와의 비교

| 측면                   | C               | Rust                  | Zig         | Rok                    |
|------------------------|-----------------|-----------------------|-------------|------------------------|
| 미초기화 표현          | `T x;` (silent) | `MaybeUninit<T>`      | `undefined` | `MaybeUninit<T>`       |
| `Pod` / 안전 transmute | **없음**        | `bytemuck::Pod` (lib) | `@bitCast`  | `Pod` + `reinterpret`  |
| 미초기화 read UB       | **허용**        | **UB**                | **UB**      | **UB**                 |
| memcpy / memmove       | `memcpy`        | `ptr::copy*`          | `@memcpy`   | `rok::bare::mem::copy*` |

## 1.3.9. `GcBuf<T>` 와 `buf_*` primitive

컬렉션의 기반인, 컴파일러가 아는 GC buffer `GcBuf<T>`는 이 module에 정의됩니다. 의미는 [2.9.12](../200-core/209-collections.md#2912-gcbuft---raw-gc-buffer)를 따르며, 거기서 `rok::core::collections::raw`가 이를 다시 내보냅니다.

```rok
struct GcBuf<T> { /* T 들의 연속 구간을 가리키는 GC 참조 하나 */ }

impl<T> GcBuf<T> {
    unsafe fn new(len: usize) -> GcBuf<T>;     // = buf_new(len)
    unsafe fn get(self, i: usize) -> T;        // = buf_get(self, i)
    unsafe fn set(self, i: usize, v: T);       // = buf_set(self, i, v)
}

unsafe fn buf_new<T>(len: usize) -> GcBuf<T>;      // 0 으로 채움
unsafe fn buf_get<T>(buf: GcBuf<T>, i: usize) -> T;        // bounds 검사 없음
unsafe fn buf_set<T>(buf: GcBuf<T>, i: usize, v: T);       // bounds 검사 없음
fn buf_same<T>(a: GcBuf<T>, b: GcBuf<T>) -> bool;  // 내용이 아니라 동일성; 아무것도 pin 하지 않음
```
