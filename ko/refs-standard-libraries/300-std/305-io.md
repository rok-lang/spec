# 3.5. `io::` - `rok::core::io`로 옮김

`rok::std::io`는 없어졌습니다. 표준 스트림을 포함한 입출력 전체가 `rok::core::io`입니다([2.23](../200-core/223-io.md)). prelude가 모듈 `io`를 들여오므로 `io::stdin()`, `io::BufReader`, `io::copy`에는 `use`가 필요 없습니다.

| 0.1 | 0.2 |
|-----|-----|
| `rok::std::io::{IoError, IoErrorKind}` | `rok::core::io::{IoError, IoErrorKind}` ([2.23.0](../200-core/223-io.md#2230-ioerror)) |
| `Reader` / `Writer` | `Read` / `Write` ([2.23.1](../200-core/223-io.md#2231-read), [2.23.3](../200-core/223-io.md#2233-write와-close)) |
| `read(buf: List<u8>)` | `read(buf: SliceMut<u8>)`; `List<u8>`도 그대로 넘어감 |
| `read_into(buf, a..b)` | `read(buf[a:b])` |
| `write(buf: List<u8>)`, `write_bytes`, `write_str`, `write_fmt` | `write<B: AsBytes>` / `write_all<B: AsBytes>` |
| `read_line() -> str` (끝에서 `""`) | `BufRead::read_line(out: StrBuf) -> usize`, `io::read_line() -> str \| none` ([2.23.2](../200-core/223-io.md#2232-bufread)) |
| `lines()` / `bytes()`의 항목 `Result<_, IoError>` | `TryIterator`: `try for l in r.lines() { .. }` |
| `stdin().lock()`, `StdinLock` | `stdin()` |
| `fs::SeekFrom` | `io::SeekFrom` |
| `byte_buf(n)` | `List::filled(n, 0u8)` |
| `raw_fd` | 없음: `io::copy`가 OS 핸들을 스스로 찾음 |
| `BufReader::buffered` | `BufReader::buffer_len` |
