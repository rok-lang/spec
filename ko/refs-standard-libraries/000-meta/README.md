## 이 장의 역할

이 장은 개별 트레잇이나 타입을 직접 정의하지 않습니다. 대신 라이브러리 **전체**가 일관되게 따라야 할 규칙과 정책을 모읍니다.

**3-tier 모델**은 의존성 방향을 정합니다. `std`는 `core`와 `bare`에, `core`는 `bare`에 의존할 수 있습니다. 반대 방향으로는 의존할 수 없습니다. **import 정책**은 `use rok::core::**;`를 묵시적으로 자동 적용하는 방식을 정합니다. prelude 모듈은 따로 없고, `rok::core` 전체를 가져오는 재귀 glob이 그 역할을 직접 맡습니다. 이어지는 **intrinsic** 항목은 표준 라이브러리 메서드가 컴파일러 백엔드(PrimOp 등)에 어떻게 연결되는지 다룹니다. 마지막 **lang slot** 항목은 컴파일러가 `#[lang(...)]` 속성으로 찾는 슬롯 48개가 표준 라이브러리의 어느 항목에 대응하는지 보여 줍니다.

이 정책을 먼저 정해야 [200-core/](../200-core/)의 트레잇 정의로 넘어갈 수 있습니다.
