## 이 장의 역할

이 장은 개별 트레잇이나 타입을 직접 정의하지 않습니다. 대신 라이브러리 **전체**가
일관되게 따라야 할 규칙과 정책을 정리합니다.

**3-tier 모델**은 의존성 방향을 규정합니다. `std`는 `core`와 `bare`를, `core`는
`bare`를 사용할 수 있지만, 반대 방향의 의존은 허용되지 않습니다. **import 정책**은
`use rok::core::**;`가 묵시적으로 자동 적용되는 방식을 정합니다. 별도의 prelude 모듈은 없고,
`rok::core`에 대한 재귀 glob이 그 역할을 직접 합니다. 이어지는 **intrinsic** 항목은 표준 라이브러리 메서드가
컴파일러 백엔드(PrimOp 등)에 연결되는 방식을 다룹니다. 마지막으로 **lang slot** 항목은 컴파일러가 `#[lang(...)]`
속성으로 찾는 48개 슬롯이 표준 라이브러리 항목에 어떻게 매핑되는지 보여 줍니다.

이 정책들이 정의되어야 [200-core/](../200-core/)의 트레잇 정의로 넘어갈 수 있습니다.
