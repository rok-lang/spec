# 3.5. `io::` - moved to `rok::core::io`

`rok::std::io` is removed. All of I/O, the standard streams included, is `rok::core::io` ([2.23](../200-core/223-io.md)), and the prelude names the module `io`: `io::stdin()`, `io::BufReader`, `io::copy` need no `use`.

| 0.1 | 0.2 |
|-----|-----|
| `rok::std::io::{IoError, IoErrorKind}` | `rok::core::io::{IoError, IoErrorKind}` ([2.23.0](../200-core/223-io.md#2230-ioerror)) |
| `Reader` / `Writer` | `Read` / `Write` ([2.23.1](../200-core/223-io.md#2231-read), [2.23.3](../200-core/223-io.md#2233-write-and-close)) |
| `read(buf: List<u8>)` | `read(buf: SliceMut<u8>)`; a `List<u8>` still passes |
| `read_into(buf, a..b)` | `read(buf[a:b])` |
| `write(buf: List<u8>)`, `write_bytes`, `write_str`, `write_fmt` | `write<B: AsBytes>` / `write_all<B: AsBytes>` |
| `read_line() -> str` (`""` at the end) | `BufRead::read_line(out: StrBuf) -> usize`, `io::read_line() -> str \| none` ([2.23.2](../200-core/223-io.md#2232-bufread)) |
| `lines()` / `bytes()` items `Result<_, IoError>` | `TryIterator`s: `try for l in r.lines() { .. }` |
| `stdin().lock()`, `StdinLock` | `stdin()` |
| `fs::SeekFrom` | `io::SeekFrom` |
| `byte_buf(n)` | `List::filled(n, 0u8)` |
| `raw_fd` | none: `io::copy` finds OS handles itself |
| `BufReader::buffered` | `BufReader::buffer_len` |
