# 2.23. `io::` - byte streams and standard I/O

`rok::core::io` holds all of Rok's I/O vocabulary: the error type, the stream traits `Read`, `BufRead`, `Write` and `Seek` with their async twins `AsyncRead`, `AsyncBufRead`, `AsyncWrite` and `AsyncSeek`, `Close` and `AsyncClose`, the buffers, `Cursor`, `copy` and the standard streams. The types that reach the OS (`File`, sockets, TLS connections, child pipes) live in `rok::std` and implement these traits; everything here is target-independent, and the standard streams exist on every target (in the browser stdout / stderr go to the host console and stdin is at its end, [0.1.4](../000-meta/001-tier-model.md)).

The prelude names the module `io` and the traits `Read`, `Write`, `AsyncRead` and `AsyncWrite`, so `io::stdin()`, `io::BufReader::new(f)` and `f.read(buf)` need no `use`. `BufRead`, `Seek`, `AsyncBufRead` and `AsyncSeek` are written `io::BufRead` and so on in bounds; their methods resolve without an import. There is no `rok::std::io`.

Every stream method has one definition: `File`, `TcpStream`, `UnixStream`, `tls::Client` and `tls::Server` have no inherent `read` / `write` / `read_to_end` / `flush` or `_async` twins of them; the calls resolve through the traits.

## 2.23.0. `IoError`

```rok
struct IoError { .. }      // private fields (0.5.10)

#[non_exhaustive]
enum IoErrorKind {
    Other,                // any other errno
    NotFound,             // ENOENT
    PermissionDenied,     // EACCES, EPERM
    AlreadyExists,        // EEXIST
    NotADirectory,        // ENOTDIR
    IsADirectory,         // EISDIR
    DirectoryNotEmpty,    // ENOTEMPTY
    InvalidInput,         // EINVAL
    BrokenPipe,           // EPIPE
    Interrupted,          // EINTR
    WouldBlock,           // EAGAIN
    TimedOut,             // ETIMEDOUT, time limit
    StorageFull,          // ENOSPC
    CrossesDevices,       // EXDEV
    Unsupported,          // ENOTSUP, ENOSYS
    UnexpectedEof,        // ended before the expected bytes (read_exact, ..)
    InvalidData,          // data does not match the format (UTF-8, ..)
    WriteZero,            // a write took no bytes before all were written
    FilesystemLoop,       // ELOOP; a final symbolic link an open with follow_symlinks: false met
    ResourceBusy,         // EBUSY, ETXTBSY; Windows: a sharing violation (another handle's share mode)
}

impl IoError {
    fn new(kind: IoErrorKind, message: str) -> IoError;        // library-raised: os_code() is none
    fn from_os_code(code: i32, context: str = "") -> IoError;  // kind and message from the OS; context (a path, a call) prefixes the message unless empty
    fn kind(self) -> IoErrorKind;
    fn os_code(self) -> i32 | none;      // errno (Windows: GetLastError / WSA code); none when the library raised it
    fn message(self) -> str;
}
// IoError implements Display, Debug, Error, PartialEq, Eq and Clone;
// IoErrorKind implements PartialEq, Eq, Clone, Copy and Debug

impl IoErrorKind {
    fn of_os(code: i32) -> IoErrorKind; // the kind of an OS error code
}
```

`kind()` comes from the OS error code (`UnexpectedEof`, `InvalidData` and `WriteZero` are set by the library); the code itself is `os_code()` and the OS description (the runtime's strerror) is `message()`. `os_code()` is `none` for an error the library raises itself (`IoError::new(InvalidInput, "..")`) and for a name that does not resolve ([3.2.4](../300-std/302-net.md)): a resolver (EAI) code is not an OS error code. Such a lookup failure keeps the resolver's message and is `NotFound` when the name does not exist, `Other` otherwise. On Windows a lookup fails with a Winsock code, which `os_code()` returns. `IoErrorKind` is `#[non_exhaustive]`: a `match` outside `rok::core` needs a `_` arm.

## 2.23.1. `Read`

```rok
trait Read {
    fn read(ref self, buf: SliceMut<u8>) throws (IoError) -> usize;  // fills buf[0..n]; 0 = end (or an empty buf)

    // low level
    fn read_vectored(ref self, bufs: Slice<SliceMut<u8>>) throws (IoError) -> usize;  // default: the first non-empty buffer
    fn read_exact(ref self, buf: SliceMut<u8>) throws (IoError);                      // all of buf, or UnexpectedEof
    fn read_to_end_into(ref self, out: List<u8>) throws (IoError) -> usize;           // appends the rest; the count

    // convenient
    fn read_to_end(ref self) throws (IoError) -> List<u8>;
    fn read_to_str(ref self) throws (IoError) -> str;           // InvalidData if not UTF-8
    fn bytes(ref self) -> Bytes<Self>;                          // TryIterator<Item = u8, Error = IoError>
    fn take(ref self, limit: u64) -> Take<Self>;                // at most limit bytes
    fn chain<R: Read>(ref self, next: R) -> Chain<Self, R>;     // this stream, then next
}
```

`read` is the one required method. A buffer is a `SliceMut<u8>` ([2.9](209-collections.md)): a `List<u8>` passes as a view of the whole list, and `buf[a:b]` reads into part of it. `read_to_end_into` reads into the list's spare capacity with no zero fill first: the exact low-level form of `read_to_end`.

`bytes`, `take` and `chain` share the stream (and `chain` its argument) with the adapter they return: the owner of an affine stream ([2.13.4](213-marker.md)) still closes it, and reads through the adapter move the shared position. `bytes` costs one `read` per byte; wrap an unbuffered stream in `BufReader` first.

## 2.23.2. `BufRead`

```rok
trait BufRead: Read {
    // low level
    fn fill_buf(ref self) throws (IoError) -> Slice<u8>;    // the buffered bytes, refilled when empty; empty = end
    fn consume(ref self, n: usize);                         // mark n buffered bytes read; panics past them
    fn read_until(ref self, delim: u8, out: List<u8>) throws (IoError) -> usize;  // appends through delim; 0 = end
    fn read_line(ref self, out: StrBuf) throws (IoError) -> usize;                // appends a line with its \n; 0 = end
    fn skip_until(ref self, delim: u8) throws (IoError) -> usize;

    // convenient
    fn lines(ref self) -> Lines<Self>;                  // TryIterator<Item = str>, \n / \r\n removed
    fn split(ref self, delim: u8) -> Split<Self>;       // TryIterator<Item = List<u8>>, delim removed
}

fn read_line() throws (IoError) -> str | none;          // stdin's next line without \n / \r\n; none at the end
```

Line and delimiter reads live only on `BufRead`, so they never cost a system call per byte. `read_line` appends to a `StrBuf` and returns the byte count, `0` at the end; a line that is not UTF-8 is `InvalidData`. `io::read_line()` is the convenient form for standard input. On an unbuffered stream, wrap it: `try for l in io::BufReader::new(f).lines() { .. }`.

`BufRead` is implemented by `BufReader<R>`, `Cursor<T>`, `Stdin` and `Empty`. The view `fill_buf` returns is valid until the next call on the stream.

## 2.23.3. `Write` and `Close`

```rok
trait Write {
    fn write<B: AsBytes>(ref self, buf: B) throws (IoError) -> usize;   // some prefix of buf; its length
    fn flush(ref self) throws (IoError);

    // low level
    fn write_vectored(ref self, bufs: Slice<Slice<u8>>) throws (IoError) -> usize;  // default: the first non-empty buffer

    // convenient
    fn write_all<B: AsBytes>(ref self, buf: B) throws (IoError);        // all of buf; WriteZero if a write takes nothing
    fn write_display<T: Display>(ref self, x: T) throws (IoError);      // x through Display, no whole str built
}

#[lang("close_trait")]
trait Close {
    fn close(self) throws (IoError);
}
```

`write` and `write_all` take anything `AsBytes` ([2.11](211-conversion.md)): a `str`, a `List<u8>`, a `Slice<u8>`, a `[u8; N]`. Formatted output is an f-string: `try w.write_all(f"{x}\n")`.

`write_display` writes one value as `print` shows it, in chunks as the value produces them (`Formatter::from_sink`, [2.10.2](210-fmt.md)), so a large value is never built as one `str`. A failed write stops the formatting and is thrown as is, the chunks before it kept. A `Display` that fails by itself becomes an `IoError` of kind `Other`.

`Close` is the resource whose close can fail ([2.13.4](213-marker.md)): its owner closes it with `try x.close()` or `using`, and leaving its scope open is an error. `File`, the sockets, the TLS connections, the child pipes, `BufReader<R: Close>`, `BufWriter<W: Write + Close>` and `LineWriter<W: Write + Close>` implement it; the buffered writers write out the rest first. Its async twin is `AsyncClose` (2.23.5); `try await x.close_async()` closes the value as `close` does.

## 2.23.4. `Seek`

```rok
enum SeekFrom { Start(u64), End(i64), Current(i64) }

trait Seek {
    fn seek(ref self, pos: SeekFrom) throws (IoError) -> u64;   // the new offset from the start
    fn rewind(ref self) throws (IoError);                       // seek(Start(0))
    fn stream_position(ref self) throws (IoError) -> u64;       // seek(Current(0))
}
```

`Seek` is implemented by `File` and `Cursor<T>`.

## 2.23.5. Async traits

```rok
trait AsyncRead {
    async fn read_async(ref self, buf: SliceMut<u8>) throws (IoError) -> usize;
    async fn read_vectored_async(ref self, bufs: Slice<SliceMut<u8>>) throws (IoError) -> usize;
    async fn read_exact_async(ref self, buf: SliceMut<u8>) throws (IoError);
    async fn read_to_end_into_async(ref self, out: List<u8>) throws (IoError) -> usize;
    async fn read_to_end_async(ref self) throws (IoError) -> List<u8>;
    async fn read_to_str_async(ref self) throws (IoError) -> str;
    fn bytes_async(ref self) -> BytesStream;             // TryStream<Item = u8, Error = IoError>
}

trait AsyncBufRead: AsyncRead {
    async fn fill_buf_async(ref self) throws (IoError) -> Slice<u8>;
    fn consume(ref self, n: usize);
    async fn read_until_async(ref self, delim: u8, out: List<u8>) throws (IoError) -> usize;
    async fn read_line_async(ref self, out: StrBuf) throws (IoError) -> usize;
    fn lines_async(ref self) -> LinesStream;             // TryStream<Item = str, Error = IoError>
}

trait AsyncWrite {
    async fn write_async<B: AsBytes>(ref self, buf: B) throws (IoError) -> usize;
    async fn flush_async(ref self) throws (IoError);
    async fn write_vectored_async(ref self, bufs: Slice<Slice<u8>>) throws (IoError) -> usize;
    async fn write_all_async<B: AsBytes>(ref self, buf: B) throws (IoError);
}

trait AsyncSeek {
    async fn seek_async(ref self, pos: SeekFrom) throws (IoError) -> u64;
}

trait AsyncClose {
    async fn close_async(self) throws (IoError);
}

async fn copy_async<R: AsyncRead, W: AsyncWrite>(r: R, w: W) throws (IoError) -> u64;
```

The async twins are separate traits: a `Read` that is not awaitable stays out of `AsyncRead` bounds, and an `await` never hides a blocking call. Their methods keep the `_async` suffix, so both kinds of method are in scope at once without ambiguity: `f.read(buf)` and `await f.read_async(buf)`. `consume` never waits and has no `_async` form; on a type that implements both `BufRead` and `AsyncBufRead` call it as `BufRead::consume(ref r, n)`.

An `AsyncRead` / `AsyncWrite` value is a handle: copies share the stream and its position. Every implementer is one: `File` (the call runs on a blocking thread, [3.1.4a](../300-std/301-fs.md#314a-asynchronous-file-io-_async)), `Socket`, `TcpStream`, `UnixStream`, `tls::Client` / `tls::Server`, the child pipes, `BufReader<R>`, `BufWriter<W>`, `LineWriter<W>`, `Cursor<T>`, `Empty`, `Sink` and `Repeat`.

The async methods take `ref self`, as their sync twins do ([refs-lang 4.12.13](../../refs-lang/004-functions/412-async.md#41213-async-on-methods)): the future holds the receiver, writes it back when it completes, and is awaited where it is made. `close_async` takes `self`: like `close`, it consumes the value.

`AsyncClose` is implemented by every `Close` type above that is also an async stream: `File` (the close runs on a blocking thread), `Socket`, `TcpStream`, `TcpListener`, `UdpSocket`, the Unix sockets, `tls::Client` / `tls::Server` (close_notify is sent without blocking), the child pipes, `BufReader<R: AsyncClose>`, `BufWriter<W: AsyncWrite + AsyncClose>` and `LineWriter<W: AsyncWrite + AsyncClose>`. A socket's close does not wait, unless `SO_LINGER` makes it wait for unsent data; then it runs on a blocking thread.

Cancel safety: a socket's `read_async` / `write_async` cancelled while suspended moved no bytes; a `File` call that is cancelled still runs on its thread, and its result is lost.

Only operations that are not stream I/O stay inherent `_async` methods of their types: opening and connecting (`open_async`, `connect_async`), `accept_async`, `shutdown_async`, datagrams (`send_async`, `recv_from_async`, ..), fd passing (`send_with_fd_async`), TLS control (`close_notify_async`, `key_update_async`) and processes (`wait_async`, `output_async`, `status_async`). The rule is [0.5.14](../000-meta/005-notation.md#0514-async-twins).

## 2.23.6. Buffers and `Cursor`

```rok
struct BufReader<R> { .. }      // implements Read + BufRead (R: Read), AsyncRead + AsyncBufRead (R: AsyncRead), Close (R: Close), AsyncClose (R: AsyncClose)
struct BufWriter<W> { .. }      // implements Write (W: Write), AsyncWrite (W: AsyncWrite), Close (W: Write + Close), AsyncClose (W: AsyncWrite + AsyncClose)
struct LineWriter<W> { .. }     // as BufWriter; writes out through the last \n of a write
struct Cursor<T> { .. }         // implements Read + BufRead + Seek and the async twins (T: AsBytes); Write over List<u8>

impl<R> BufReader<R> {
    fn new(inner: R) -> BufReader<R>;                   // 8 KiB buffer
    fn with_capacity(cap: usize, inner: R) -> BufReader<R>;
    fn into_inner(self) -> R;                           // buffered bytes are dropped
    fn buffer_len(self) -> usize;                       // bytes buffered and not yet read
    fn capacity(self) -> usize;
}

impl<W> BufWriter<W> {
    fn new(inner: W) -> BufWriter<W>;
    fn with_capacity(cap: usize, inner: W) -> BufWriter<W>;
    fn buffer_len(self) -> usize;                       // bytes written but not yet passed on
    fn capacity(self) -> usize;
}
impl<W: Write> BufWriter<W> {
    fn into_inner(self) throws (IoError) -> W;          // writes out the rest, then returns the writer
}

impl<W> LineWriter<W> { fn new(inner: W) -> LineWriter<W>; }
impl<W: Write> LineWriter<W> { fn into_inner(self) throws (IoError) -> W; }

impl<T> Cursor<T> {
    fn new(inner: T) -> Cursor<T>;
    fn position(self) -> u64;
    fn set_position(self, pos: u64);
    fn get_ref(self) -> T;
    fn into_inner(self) -> T;
}
```

The buffers and `Cursor` are handles: copies share the buffer and the position. `BufWriter` over a `Close` writer is closed by its owner: `close()` writes out the rest and closes the inner writer, so a buffered write error is never lost. A `Cursor<List<u8>>` overwrites from the position and then extends the list.

```rok
using r = io::BufReader::new(try fs::open("data.txt")) {
    try for line in r.lines() {
        println(line);
    }
}
```

## 2.23.7. `copy` and utilities

```rok
fn copy<R: Read, W: Write>(ref r: R, ref w: W) throws (IoError) -> u64;

fn empty() -> Empty;            // Read + BufRead: always at the end
fn sink() -> Sink;              // Write: discards every byte
fn repeat(byte: u8) -> Repeat;  // Read: an endless stream of byte

struct Take<R> { .. }           // r.take(n); limit(), set_limit(n), into_inner()
struct Chain<A, B> { .. }       // a.chain(b); into_inner()
```

`copy` reads `r` to its end into `w` and returns the byte count. Between two OS handles (files, sockets without timeouts or non-blocking mode, pipes) the runtime lets the kernel move the bytes (`copy_file_range` / `sendfile` / `splice`); other streams copy through `read` / `write_all` with an 8 KiB buffer.

## 2.23.8. Standard streams

```rok
fn stdin() -> Stdin;            // Read + BufRead
fn stdout() -> Stdout;          // Write
fn stderr() -> Stderr;          // Write
fn read_line() throws (IoError) -> str | none;
```

`stdout()` shares the runtime buffer of `print` / `println`, so mixed output keeps its order; the buffer is flushed at a newline on a terminal, when full, at `flush()` and at exit. `stderr` is unbuffered. `stdin()` reads through the runtime's shared buffer; a `Stdin` handle buffers at most the rest of one line for `fill_buf`, so lines it has not consumed stay with that handle.

## 2.23.9. Examples

```rok
// line by line from stdin
while let line: str = try io::read_line() {
    process(line);
}

// a file, buffered, closed on the way out
using w = io::BufWriter::new(try fs::create("out.txt")) {
    for x in xs {
        try w.write_all(f"{x}\n");
    }
}

// a part of a buffer
let buf = List::filled(4096, 0u8);
let n = try conn.read(buf[0:512]);

// copy
using src = try fs::open("a.txt") {
    using dst = try fs::create("b.txt") {
        try io::copy(ref src, ref dst);
    }
}
```
